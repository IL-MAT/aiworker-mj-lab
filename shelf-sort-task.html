    3단 선반-박스 색상 분류¶

    전방 3단 선반에서 캔을 집어 로봇 기준 왼쪽 테이블의 빨강 박스 또는 오른쪽 테이블의 파랑 박스로 옮기는 작업환경이다. 기존 캔·상자 환경과 분리되어 있으며 실행할 때 --env 2를 선택한다.

    python src/teleop_app.py --env 2

    작업공간¶

    위치 모델 역할
    전방(+X) 회색/목재 3단 선반 물체를 집는 source shelf
    왼쪽(+Y) 테이블 위 빨강 박스 빨강 캔의 목적지
    오른쪽(-Y) 테이블 위 파랑 박스 파랑 캔의 목적지

    캔은 source shelf의 중간 단에서 시작한다. reset할 때 빨강 또는 파랑으로 선택되며 같은 색 목적지 박스 안에 안정적으로 놓으면 성공이다. R을 누르면 색과 시작 위치를 다시 뽑는다.

    선반 외형은 프레임과 판재를 조립하는 생성 스크립트로 직접 모델링한 OBJ mesh다. 정면에는 물체를 꺼낼 때 걸리는 턱이나 가림막이 없다. 물리는 뒷판 하나, 좌우 측면 하나씩, 세 선반판까지 총 6개의 큰 box collision으로 근사한다. 네 기둥을 네 개의 작은 collision으로 쪼개지 않고 좌우 측면 proxy로 합쳐 틈과 계산량을 줄였다. 좌우 테이블은 상판만 collision으로 사용하고 다리는 시각 모델로만 표시한다. 실시간 CBF는 이 중 세 선반판과 두 테이블 상판만 감시하고 나머지는 MuJoCo 물리 접촉이 처리한다. 작업공간 배치는 models/shelf_sort_workspace.xml, mesh 생성 과정은 tests/generate_shelf_mesh.py에 있어 로봇 모델을 복제하지 않고 독립적으로 수정·재생성할 수 있다.

    모바일 베이스 collision은 기존 0.40 × 0.40 m 상자 대신 실제 chassis 외곽을 단순화한 0.645 × 0.62 m 크기의 convex 10각 기둥 하나를 사용한다. 높이는 테이블 밑면과 겹치지 않는 하부 chassis까지만 덮고, 바퀴 collision은 지면 구동용으로 별도 유지한다. 10각 proxy는 assets/collision/base_chassis_collision.obj에 있다.

    macOS operator view는 로봇의 원본 visual mesh를 그대로 사용한다. 약 100만 삼각형을 여러 번 그리던 그림자 맵과 바닥 반사 패스만 macOS에서 비활성화해 원본 외형을 유지하면서 30 Hz 표시 주기를 확보한다. 물리는 600 Hz로 적분해 화면 프레임당 정확히 20번 진행하고, 기존 25 Hz imitation 환경에서는 24번 진행한다. V 디버그 화면과 물리 접촉에만 별도의 convex collision proxy를 사용하며 tests/generate_collision_lods.py로 재생성할 수 있다.

    권장 조작 순서¶

    1. Whole-body ON, 양팔 IK, controller MoveL을 선택한다.
    2. 색을 확인하고 Up으로 source shelf 가까이 이동한 뒤 키를 놓아 정지한다.
    3. 물체와 가까운 손 target을 중간 단의 캔 양옆으로 이동한다.
    4. Grab으로 파지하고 손 target을 위쪽과 로봇 쪽으로 빼 선반에서 꺼낸다.
    5. [/]와 방향키로 색이 맞는 좌우 테이블 앞으로 이동한다.
    6. 목표 박스 안으로 캔을 천천히 내린 뒤 Release한다.

    V를 켜면 상세 visual을 숨기고 선반, 좌우 테이블과 색상 박스의 collision geometry만 불투명 파랑으로 표시한다. visual과 반투명 collision이 같은 면에 겹쳐 깨져 보이는 현상을 피하기 위한 collision-only 보기다. 렌더 단계에서는 CBF 최근접점 거리와 선을 중복 계산하지 않는다. 손가락과 캔의 접촉은 파지를 위해 그대로 허용된다. 좁은 선반 안에서 큰 target 이동을 한 번에 주기보다 5~20 mm씩 나누어 이동하는 편이 안정적이다.

    모델 좌표와 치수¶

    • source shelf 중심: (0.95, 0.00) m, 폭 0.76 m, 깊이 0.38 m
    • 빨강 테이블 중심: (0.39, +0.62) m, 박스 중심 높이 0.7125 m
    • 파랑 테이블 중심: (0.39, -0.62) m, 박스 중심 높이 0.7125 m
    • 두 테이블 사이 빈 폭: 0.70 m (베이스 10각 collision 폭 0.62 m)
    • 빨강/파랑 박스 바닥: 가로 0.28 m, 세로 0.28 m (높이는 기존과 동일)
    • 선반판 중심 높이: 0.43, 0.755, 1.08 m
    • 중간 단 캔 중심 높이: 0.835 m

    기존 --env 0, --env 1에서는 이 선반·테이블 geometry와 marker가 숨겨지고 충돌도 비활성화되므로 기존 테이블 작업에 영향을 주지 않는다.
